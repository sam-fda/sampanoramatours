# Space & Matter — Panorama Viewer

A minimal, monochrome 360° panorama system for **Enscape equirectangular exports**, in the
Space & Matter identity. Built on [Marzipano](https://www.marzipano.net/) (bundled locally).

It has **two roles**:

| Page | Who | What it does |
|---|---|---|
| **`admin.html`** | You (admin) | Build a tour: load panoramas, set the view limits, aim each scene, then export `config.js` + QR codes. |
| **`viewer.html`** | Guests | The locked viewer a guest reaches by scanning a QR. It obeys your limits — guests **cannot** change zoom/angle. |

`index.html` just forwards to `viewer.html`, so the hosted folder's bare URL opens the tour.

---

## Build a tour (admin)

1. Open **`admin.html`** (double-click, or host it privately).
2. **Drop your Enscape exports** into the panorama list. Each becomes a scene; rename it,
   reorder with ↑ ↓, remove with ✕.
3. For each scene, **drag to the direction you want guests to start facing**, then press
   **Set front to current view**. That fixes the opening view *and* centres the horizontal arc.
4. Set the **View limits** (they apply to every scene, and this is the *only* place they're set):
   - **Zoom in / out limits** — tightest and widest field of view.
   - **Limit horizontal pan** — turn off full 360° and give an **arc width** (e.g. 200°).
   - **Limit vertical pan** — cap **Up** / **Down** independently to hide the blurry
     sky/ground poles of an Enscape render (a good start is Up 55°, Down 35°).
5. **Optimise for web** (important — see below) → downloads lighter JPG copies.
6. Enter your **Hosted base URL** (e.g. `https://spaceandmatter.nl/tours/tower/`), then
   **Download config.js** and **Generate QR codes** (one per panorama).

## Publish & host

For each tour, upload a folder to your web space containing:

```
viewer.html      marzipano.js      config.js      panos/  (the optimised JPGs)
```
(`index.html` optional; `admin.html` and `qrcode.min.js` are only needed for authoring and
don't have to be uploaded.)

- A QR encodes `…/viewer.html?start=<scene-id>` — scanning it opens the tour **at that
  panorama**, and the guest can hop to the others from the bottom slider.
- It's all static files, so any host works — your Webflow/webpage space, Netlify, GitHub
  Pages, an S3 bucket, etc. No server code.

> **Formats:** JPG **and PNG** both work. **But** your sample PNG is 16384×8192 / ~88 MB —
> that won't render on many phones (mobile GPUs cap textures at 4096–8192 px) and is a huge
> download. The **Optimise for web** step fixes this: 4096 px ≈ **630 KB**, 8192 px ≈ 1.8 MB.
> Use 4096 px for a QR-on-a-poster guest audience; since you set a zoom-in limit anyway, the
> extra resolution isn't visible.

## `config.js` shape

```js
window.TOUR = {
  title: "Vlinderhaven — Tower",
  settings: { fovMin:40, fovMax:100, yawLimited:false, yawRange:200,
              pitchLimited:true, pitchUp:55, pitchDown:35 },
  scenes: [
    { id:"tower", name:"Tower — exterior", file:"panos/tower.jpg", front:{yaw:0, pitch:0} }
  ]
};
```
Hand-editable if you ever want to tweak without reopening the admin page.

## Swap in the real logo

Header + splash use a placeholder ampersand tile. To use the official mark, drop `logo.png`
in the folder and, in `viewer.html` (and `admin.html`), add `background-image:url(logo.png)`
to `.brand-mark` / `.mark` and remove the `<span>&amp;</span>`. Brand colours are the
`:root` tokens at the top of each file (`--ink #191919`, `--paper #fff`, …).

## Files

```
admin.html      tour builder (authoring only)
viewer.html     locked guest viewer  ← QR codes point here
index.html      redirect → viewer.html
config.js       tour definition (generated by admin.html; hand-editable)
marzipano.js    360° engine (Marzipano 0.10.2, Apache-2.0)
qrcode.min.js   QR generator (authoring only)
logo.png        placeholder mark — replace with the official logo
panos/          panorama images (put optimised JPGs here for hosting)
```

There's also a self-contained web demo (Marzipano via CDN, a sample panorama baked in) for
showing the look on a phone — ask for the shared artifact link.
